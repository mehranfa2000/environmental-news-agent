# 🌿 Environmental News Agent v4

ربات هوشمند اخبار محیط زیست — فوق حرفه‌ای

## ویژگی‌ها

- 📡 **۱۲۰+ منبع RSS** از ایران و جهان
- ⚡ **دریافت موازی** — همه منابع همزمان (۷× سریع‌تر)
- 🧠 **فیلتر سه‌لایه** — سیاه‌لیست + امتیاز عنوان + امتیاز کل

- 📸 **تصویر شاخص** در تلگرام
- 📊 **خلاصه روزانه** هر شب ساعت ۲۲
- 🏥 **سلامت‌سنجی منابع** + غیرفعال‌سازی خودکار
- 📋 **صف پیام‌های ناموفق** — هیچ خبری از دست نمی‌رود
- 🗂️ **۸ دسته‌بندی** محیط زیستی
- 📅 **تاریخ شمسی** با نام روز هفته
